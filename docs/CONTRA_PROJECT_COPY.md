# Contra Project Copy

## Project title

CAIRN — Accessible Revenue Intelligence Dashboard

## Short description

A premium React dashboard redesigned as a keyboard-operable, responsive, regression-tested revenue workflow.

## Project overview

CAIRN is a self-initiated technical case study for a fictional revenue-intelligence platform. I designed and built the interface, then treated accessibility as a product-engineering problem: semantic structure, keyboard behavior, visible state, chart alternatives, focused form errors, responsive layouts, and automated regression coverage.

The result preserves a high-end editorial brand while making a complex dashboard easier to operate and understand.

## The challenge

Dense B2B dashboards often depend on color, pointer interactions, unlabeled controls, and visual-only charts. Those patterns create barriers for keyboard and assistive-technology users and leave engineering teams without reliable regression evidence.

## What I delivered

- Premium responsive React and TypeScript interface
- Interactive forecast tabs and evidence-backed deal filters
- Semantic navigation, landmarks, headings, lists, and dialogs
- Keyboard widget behavior and visible selected states
- Non-color status communication and accessible chart alternative
- Focused validation feedback and reduced-motion support
- Playwright and axe-core regression tests
- Reproducible controlled baseline fixture and audit documentation

## Verification

Five end-to-end scenarios pass, including keyboard tabs, filter state, form validation, skip navigation, mobile overflow, and configured axe scans. The project does not claim certification or completed screen-reader validation.

## Services demonstrated

Accessibility remediation · React/Next.js front-end engineering · WCAG-oriented UI review · Playwright/axe regression testing · Responsive product design · Complex dashboard UX
