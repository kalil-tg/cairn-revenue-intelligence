# CAIRN Design System

## Direction

CAIRN combines an editorial serif voice with a precise enterprise dashboard. The visual system uses large typography and generous off-white space for narrative sections, then switches to dark product surfaces where data density increases.

## Foundations

- Display type: Cormorant Garamond
- Interface type: Manrope
- Paper: warm off-white
- Ink: near-black
- Accent: vivid signal orange
- Supporting UI: restrained grays, rules, and explicit status labels

Orange is a directional signal, not the only carrier of meaning. Bright orange buttons use dark text to preserve readable contrast.

## Layout

- Wide editorial shell with consistent page gutters
- Oversized, tight-leading section headlines
- Two-column narrative/product compositions on desktop
- Single-column reflow and collapsible navigation on smaller screens
- Thin rules, square signal markers, and diagram-like connectors for continuity

## Components

- Primary and secondary calls to action
- Forecast tab interface with keyboard roving focus
- Labeled quarter selector
- Evidence-backed opportunity explorer
- Filter group with selected state
- Native modal dialogs for access request and product tour
- Semantic activity timeline and recommended-action lists

## Interaction principles

1. Every action has an accessible name.
2. Selection is represented in text or state, never color alone.
3. Keyboard behavior follows the expected widget pattern.
4. Validation moves focus to the message that requires action.
5. Animation is optional and reduced when the operating system requests it.
